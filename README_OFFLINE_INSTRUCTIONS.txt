HOW TO RUN / USE OFFLINE:
--------------------------------------------------------------------------------
OPTION A (EASIEST — ZERO INSTALLATION REQUIRED):
1. Unzip this package to any folder on your computer.
2. Double-click "index.html" to open it in Chrome, Firefox, Safari, Edge, or Brave.
   Everything runs locally in your browser with no internet connection needed!

OPTION B (LOCAL WEBSERVER USING NODE.JS):
1. Open your terminal / command prompt in the extracted folder.
2. Run: node server.js
3. Open your browser to: http://localhost:3000

OPTION C (LOCAL WEBSERVER USING PYTHON 3):
1. Open your terminal / command prompt in the extracted folder.
2. Run: python3 -m http.server 3000
3. Open your browser to: http://localhost:3000


HOW TO PRINT THE BINDER CHEAT SHEET:
--------------------------------------------------------------------------------
1. Open index.html in your browser.
2. Click the "🖨️ Binder Cheat Sheet" tab or the "Print Notes" button in the top right.
3. Press Ctrl+P (or Cmd+P on Mac).
4. The custom print stylesheet will automatically re-format the content into a crisp,
   clean, high-density black-and-white cheat sheet ready for your Science Olympiad
   3-ring binder or note sheet!
